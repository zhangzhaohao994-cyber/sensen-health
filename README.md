# 森森 SENSEN

以手机阅读为优先的静态品牌网站，部署于 GitHub Pages。

网站：https://zhangzhaohao994-cyber.github.io/sensen-health/

首页第一屏仅呈现品牌主张与导航；服务、智能产品、项目、团队、会员、资源、合作与公开动态各有独立页面。无外部字体或脚本 CDN，无注册、支付或健康资料上传。沟通清单在浏览器本地生成。

## 编辑与运行

直接编辑根目录的 HTML、styles.css、app.js、data.js。任意静态服务器即可预览。GitHub Pages 使用 main 分支根目录，.nojekyll 关闭 Jekyll 处理。

## 开源设计

文字裁切、交错入场及全屏菜单结构参考并改编自 [Codrops SuperfluidLayout](https://github.com/codrops/SuperfluidLayout/tree/92dcc855e21bc8b843a55f37ef82e1b6e9dc227e)，MIT 许可保存在 licenses/SuperfluidLayout-MIT.txt。动效用浏览器原生 Web Animations API 实现，支持减少动态效果偏好。
