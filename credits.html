清晰的内容，也应有清晰的出处。这里记录本网站采用的开源设计、动画实现与公司资料使用方式。

01 / 设计与动效

来自开源实验，重新为手机设计。

网站参考并改编了 Codrops 的 SuperfluidLayout 固定版本。它以克制的版面、留白和大字导航组织内容，采用 MIT 许可。

具体复用了 overflow 容器中的文字裁切方式，以及菜单项目交错进入、交错退出的动画编排。网站根据中文阅读与手机触屏重新调整了字号、间距、导航和信息结构。

动画使用浏览器原生 Web Animations API 实现，替代原示例中的 GSAP，并支持系统的“减少动态效果”偏好。字体、图片和网站代码由本站提供，无需访问外部字体或脚本 CDN 才能阅读内容。

02 / 公司资料与素材

将资料整理成可阅读的网站。

公司介绍、团队成员、项目经历与服务信息依据公司提供的介绍资料整理。页面经过结构重组与文字提炼，便于了解公司的定位、能力与合作方式。

网站中的品牌标识、人物照片及公司相关图片用于呈现对应的公司、成员和项目。移动端图片仅作等比例缩小与编码优化，不改变人物身份或图片内容；透明素材保留透明背景。

本站不提供原始项目介绍 PDF 的公开下载，也不发布内部整理报告或私人资料。开源设计的许可不构成公司品牌、人物肖像或项目素材的转载许可。
